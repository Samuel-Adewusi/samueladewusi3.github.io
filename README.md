# Samuel Adewusi — Data Engineer Portfolio

## About

I'm a Data Engineer with experience building and maintaining ETL/ELT
pipelines, orchestrating workflows with Apache Airflow, and modeling data
warehouses with dbt, alongside a background in data analysis and BI
reporting.

This site includes my professional summary, technical skills, and three
end-to-end data engineering projects I designed and built independently:

- **[ETL Weather Pipeline](https://github.com/Samuel-Adewusi/etl-weather-pipeline)** — containerized Python/PostgreSQL ETL pipeline with automated tests
- **[Airflow Weather Orchestration](https://github.com/Samuel-Adewusi/airflow-weather-orchestration)** — Airflow DAG with dynamic task mapping, a data-quality gate, and success/failure notifications
- **[dbt E-Commerce Warehouse](https://github.com/Samuel-Adewusi/dbt-ecommerce-warehouse)** — star-schema dimensional model with dbt tests and CI
